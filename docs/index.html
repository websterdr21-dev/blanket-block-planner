Getting started

Blanket Block Planner

installing it, then using it

Part one — putting it on your phone

Open this page on the phone you want the app on, then tap the button. If you are reading this on a computer, send yourself the link and open it on the phone instead.

Download the app Android 7 or newer · about 5 MB

Nothing happens automatically — the phone will ask you a few things first.

The app doesn't come from the Play Store, so your phone asks whether you're sure a few times along the way. That's normal. The wording below is roughly what you'll see; your phone may put it slightly differently.

You only do this once. After that it's an app on your phone like any other.

  1. Keep the download

    Your phone will say something like This type of file can harm your device. Do you want to keep blanket-block-planner.apk anyway? Tap Download anyway, or OK. Your phone says this about anything that didn't come from the Play Store — it hasn't found anything wrong.

  2. Open the downloaded file

    When it finishes, a notification appears saying the download is complete. Tap it.

    If you've already swiped that away, open the Files app (or My Files on a Samsung), go to Downloads, and tap blanket-block-planner.apk.

  3. Let this one app be installed

    Your phone will say something like For your security, your phone currently isn't allowed to install unknown apps from this source. Tap Settings on that message. A switch appears called Allow from this source — turn it on. Then press the back arrow.

    This only applies to whichever app you downloaded from, usually Chrome, and you can switch it back off afterwards if you'd rather.

  4. Install

    You should be back on a screen showing Blanket Block Planner with an Install button. Tap it.

  5. Get past the last warning

    Play Protect may say Unsafe app blocked, or This app wasn't scanned by Play Protect. Tap More details, then Install anyway. If it offers to Send app for scanning, you can choose Don't send.

    Google says this about anything it hasn't seen in the Play Store before. It isn't a virus warning.

  6. Open it

    Tap Open, or find Blanket Block Planner with your other apps — the icon is nine little coloured squares on a dark blue background. Hold it and drag it onto your home screen so it's easy to find next time.

    Be on wifi the very first time you open it, so it can check for anything newer. After that it works with no signal at all.

If you opened this from WhatsApp

WhatsApp's own little browser sometimes won't download the file. Tap the three dots in the corner and choose Open in browser, then use the button again.

Part two — using it

What it does

You photograph each of your blocks and say how many of each you've made. It works out an arrangement and shows you the whole blanket before you sew a stitch of it together.

  1. Get your blocks in

    Take a photo opens the camera for one block at a time. Choose from gallery lets you tick several photos you've already taken and bring them in at once.

    You only need one photo of each different pattern, not one per block. Made twelve of the navy rose? Photograph it once, and type 12 in a moment.

  2. Let it draw each one

    It says drawing a clean version of this block… for a second or two, then the photo becomes a neat flat drawing. That drawing is what you'll see in the finished plan.

  3. Name them and count them

    Give each a name you'll recognise — navy rose, green centre — and type how many you've finished. If most have the same count, type it once under Set qty for all, tap Apply to all, then fix the odd ones.

  4. Add them, then set the size

    Tap Add to blanket. Then put in rows and columns, or tap Auto-suggest size and it picks a sensible shape. The line underneath tells you if blocks will be left over, or cells left empty.

  5. Pick the look you want

    Under Pattern style there are six ways to arrange the same blocks:

    • Scattered — all mixed up, with no two of the same touching.
    • Stripes — a different pattern along each row.
    • Diagonals — patterns running corner to corner.
    • Checkerboard — alternating, like a chessboard.
    • Framed — one pattern all the way round the edge, the rest inside.
    • Rings — rings working inwards from the outside.

    Try them all. Changing it and tapping generate again costs nothing.

  6. Generate the layout

    Tap Generate layout. The grid shows where each block goes, with a list underneath naming each one. Don't like the arrangement? Tap it again.

    The line below the grid tells you how it got on. On Scattered it says whether it kept every matching pair apart. On the others it says how many squares follow the pattern — if you haven't quite enough of one block it fills the rest in with what's left, rather than giving up.

Taking a good photo

  • DoLay the block flat, hold the phone straight above it.
  • DoPut it on something plain, in a different colour from the block.
  • DoGet the whole block in, with a little space around all four edges.
  • DoUse daylight where you can.
  • SkipYour own shadow falling across the block.
  • SkipA busy tablecloth, or a background the same colour as the block.

A loose tail of yarn hanging off the block is fine — it knows to ignore those.

It remembers where you left off

Close the app whenever you like. Next time you open it, your blocks, the size you chose and the last layout it worked out are all still there. Nothing is sent anywhere — it's all kept on the phone.

When you want to start a fresh blanket, tap Start a new blanket underneath your list of blocks.

If it says blocks are touching

On the Scattered style it sometimes says it couldn't keep every matching pair apart. Not a fault — the numbers make it impossible, usually because one pattern makes up too much of the blanket. Tap generate again, or make a couple more of a different block.

On the other five styles, matching blocks sitting next to each other is the whole point, so it doesn't mention it.

Sending changes later

You almost never send another APK. Edit www/index.html, commit, then:

powershell -File publish-update.ps1

Her app checks on launch, downloads in the background, and runs the new version next time she opens it. She needs signal for that check only.

A new APK is only needed for a native change — a plugin, or the icon. Then rebuild and upload it under the same filename so the link keeps working:

gh release create v1.1 blanket-block-planner.apk
